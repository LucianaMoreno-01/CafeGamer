# CafeGamer ☕🎮

Proyecto web desarrollado para la gestión y presentación de una temática gamer/café, estructurado con tecnologías web estándar.

## Tecnologías Utilizadas 🛠️
- **HTML5**: Estructura principal de las páginas.
- **CSS3**: Estilos, diseño y maquetación (`style.css`).
- **JavaScript**: Interactividad y lógica del sitio (`script.js`).
